# Стандарты разработки

## Git и ветки
- Trunk-based: короткоживущие ветки от `main`, частые мелкие PR.
- Название ветки: `feature/<jira-key>-краткое-описание`.
- Каждый PR привязан к задаче Jira.

## Code review
- Минимум 1 аппрув, для критичных сервисов — 2.
- Ревью в течение рабочего дня; блокеры — приоритет.
- Автотесты и линтер должны быть зелёными до мержа.

## Тесты и CI
- Юнит-тесты обязательны для новой логики.
- Пайплайн CI: линтер → тесты → сборка → деплой на stage.
- Прод-деплой — через релизный процесс, не напрямую.

## Чек-лист первого PR новичка
1. Ветка от `main`, привязка к Jira-задаче.
2. Тест на изменение.
3. Зелёный CI.
4. Ревью бадди.

Подробности процесса адаптации — [Чек-лист онбординга](onboarding-checklist).
