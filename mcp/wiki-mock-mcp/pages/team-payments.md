# Команда «Платёжные сервисы»

Отвечаем за переводы, СБП и эквайринг. Стек: Python (FastAPI), PostgreSQL,
Kafka, Kubernetes. Репозитории в корпоративном GitLab, задачи в Jira (проект
`SCRUM`).

## Регулярные встречи (добавить новичка)
| Встреча | Когда | Кого добавить |
|---------|-------|---------------|
| Дейли-стендап | Пн–Пт 10:00 | всю команду |
| Груминг бэклога | Вт 15:00 | всю команду |
| Планирование спринта | Пн (раз в 2 нед) 11:00 | всю команду |
| Ретро | Пт (раз в 2 нед) 16:00 | всю команду |
| 1:1 с бадди | еженедельно | новичок + бадди |
| 1:1 с руководителем | раз в 2 нед | новичок + PO |

## Роли
- **PO / руководитель группы** — согласует план ИС, доступы.
- **Бадди** — сопровождает новичка первые недели (см. [Программа бадди](buddy-program)).
- **Тимлид по дежурствам** — вводит в мониторинг и алерты.
