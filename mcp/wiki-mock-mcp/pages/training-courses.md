# Каталог обучающих курсов

Курсы на внутренней LMS. Для новичка-backend рекомендуется пройти отмеченные
как «обязательно» в первую неделю/месяц.

| Курс | Кому | Когда | Обязательность |
|------|------|-------|----------------|
| Security Basics (безопасная разработка) | все | 1-я неделя | **обязательно** |
| Работа с персональными данными (152-ФЗ) | все | 1-я неделя | **обязательно** |
| Введение в платёжные системы и СБП | backend платежей | 1-й месяц | обязательно |
| Внутренние стандарты разработки | все инженеры | 1-й месяц | обязательно |
| Kubernetes для разработчиков | backend | 1–2 месяц | рекомендуется |
| Kafka: паттерны и антипаттерны | backend платежей | 1–2 месяц | рекомендуется |
| Наблюдаемость: логи, метрики, трейсинг | backend | 2-й месяц | рекомендуется |

## Как назначаются курсы
Онбординг-агент подбирает 3–5 курсов по роли и команде из этого каталога и
предлагает их новичку; обязательные ставятся в план на испытательный срок в Jira.
