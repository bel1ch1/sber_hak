# О компании

Мы — цифровой блок крупного банка. Строим платёжные и клиентские сервисы,
которыми ежедневно пользуются миллионы людей. Инженерная культура: автономные
команды, trunk-based разработка, сильная культура ревью и безопасности.

## Ключевые домены
- **Платёжные сервисы** — переводы, эквайринг, СБП.
- **Клиентские сервисы** — мобильное и веб-приложение.
- **Данные и ML** — рисковые модели, антифрод, персонализация.
- **Платформа** — инфраструктура, CI/CD, наблюдаемость.

## Как всё устроено
Каждая команда владеет своими сервисами end-to-end (you build it — you run it).
Общие правила разработки — на странице [Стандарты разработки](dev-standards).
Процесс адаптации новичка — [Чек-лист онбординга](onboarding-checklist).
