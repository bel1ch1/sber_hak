# Программа бадди

Каждому новичку назначается **бадди** — опытный коллега из команды, который
помогает адаптироваться первые 4–6 недель.

## Обязанности бадди
- Еженедельные 1:1 с новичком.
- Помощь с окружением, первым PR, знакомством с командой.
- Ответы на «глупые вопросы» без эскалации к руководителю.

## Как выбирается бадди
- Из той же команды, близкий стек.
- Не перегружен (не более 1 активного новичка).
- Учитывается история: бадди, чьи прошлые онбординги проходили гладко
  (мало правок от руководителя), приоритетнее. Онбординг-агент ранжирует
  кандидатов по накопленным карточкам исходов.

## Критерии успешного бадди-периода
- Новичок сделал первый PR на 1-й неделе.
- Новичок понимает, к кому идти с каким вопросом.
- Нет заблокированных задач из-за отсутствия знаний/доступов.
