Форма заявки на выбор систем

1. Заполнение заявки

  1. ФИО заявителя
    Введите свои фамилию, имя, отчество в поле «ФИО».
  2. Организация
    Укажите вашу организацию.
  3. Email вашего руководителя
    Укажите email вашего руководителя.
  4. Выбор прав доступа
    Выберите нужный путь из меню. Для каждого пути доступны подкатегории и варианты выбора. Можно добавить несколько путей к заявке.

2. Завершение и отправка заявки

    После заполнения всех обязательных полей:
    • Нажмите кнопку «Отправить результат» — откроется почтовый клиент с готовым письмом. Созданное письмо будет отправлен вашему руководителю для согласования выбранных Вами прав или доступов.
    • Либо используйте кнопку «Скопировать заявку» — текст заявки скопируется в буфер обмена.
    • Либо используйте кнопку «Скачать заявку» — заявка будет сохранена в виде текстового файла.

3. Важные моменты

  • Обязательные поля отмечены звёздочкой (*).
  • Без заполнения обязательных полей отправка, копирование или скачивание заявки будет недоступно.
  • Форма работает полностью автономно, не требует подключения к интернету или серверу.
  • Все данные остаются только на вашем устройстве.
